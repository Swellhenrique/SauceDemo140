# 🧪 SauceDemo140 — Automação de Testes Web

## 📌 Sobre o projeto

Este projeto tem como objetivo automatizar testes funcionais de uma aplicação web de e-commerce, utilizando Python, Selenium WebDriver e PyTest.

A automação valida funcionalidades essenciais do fluxo de compra, desde o login até a interação com o carrinho de compras, contribuindo para a verificação da qualidade e do comportamento esperado da aplicação.

O projeto foi desenvolvido como parte da minha prática em Quality Assurance (QA), aplicando conceitos de automação de testes, validações, organização de scripts e boas práticas de programação.

## 🎯 Objetivos

- Automatizar cenários de testes funcionais em uma aplicação web.
- Validar o fluxo de navegação e compra.
- Verificar informações e comportamentos esperados da aplicação.
- Utilizar asserções para validar os resultados dos testes.
- Desenvolver conhecimentos práticos em automação de testes com Python.

## 🛠️ Tecnologias utilizadas

- **Python** — linguagem de programação.
- **Selenium WebDriver** — automação da interação com o navegador.
- **PyTest** — execução e organização dos testes automatizados.
- **Git e GitHub** — versionamento e hospedagem do projeto.

## 🧪 Cenários de teste automatizados

| ID | Cenário | Objetivo |
|---|---|---|
| CT01 | Login | Validar o acesso à aplicação. |
| CT02 | Listagem de produtos | Verificar a exibição dos produtos disponíveis. |
| CT03 | Dados do produto | Validar o nome e o preço dos produtos. |
| CT04 | Adicionar ao carrinho | Verificar se o produto é adicionado corretamente. |
| CT05 | Validar carrinho | Conferir a quantidade e os dados dos produtos adicionados. |
| CT06 | Remover produto | Verificar se o produto é removido do carrinho. |
| CT07 | Logout | Validar o encerramento da sessão. |

*Os cenários devem corresponder aos testes presentes no código atual do projeto.*
